Tips & safeguards

• Batch पूरा होने पर उसके प्रश्न तुरन्त सेव होकर दिखते हैं। Output बड़ा होने या JSON कटने पर एक batch अपने-आप छोटे पेज समूहों में दोबारा प्रोसेस हो सकता है।
• लाल/पीले warning वाले सवाल पहले जाँचें। AI अस्पष्ट उत्तर का अनुमान नहीं लगाएगा।
• Retry failed batches केवल असफल पेज फिर से चलाने की कोशिश करता है; सफल batches दोबारा नहीं चलने चाहिए।
• Railway Volume को /app/data पर mount करें ताकि job data और retry के लिए मूल PDF deployments के बाद उपलब्ध रहें। Public link साझा न करें; APP_PASSWORD मजबूत रखें।
• HTML import / linked image extraction अभी समर्थित नहीं है; image-based HTML को PDF में export करके upload करें।
